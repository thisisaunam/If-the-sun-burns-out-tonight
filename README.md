# if the sun burns out tonight.

> *What would you choose to preserve?*

A small interactive experience about endings, memory, and the things we decide are worth carrying with us.

The sun is going out.

You have enough light for one thing.

So you choose.

And then you watch what happens to it.

---

## The Idea

**If the Sun Burns Out Tonight** is an interactive story built around one simple question:

> **When everything disappears, what would you want to remain?**

The experience takes you through six acts — from the last moments of the sun to a sky made from the memory you chose.

A memory becomes light.
Light becomes fragments.
Fragments become a constellation.

And eventually, the question changes:

> **What would you leave behind for someone who never knew you?**

It's meant to be experienced slowly.

---

## The Six Acts

### Ⅰ — The Dying Light

*What if everything ends?*

The sun is fading. The last night begins.

### Ⅱ — The Choice

*What matters to you?*

You choose one thing to preserve — from a voice or a photograph to something completely personal.

### Ⅲ — The Last Light

*Can it survive?*

Your choice becomes a single point of light.

### Ⅳ — The Collapse

*What happens when everything is gone?*

The memory begins to disappear.

Slowly.

### Ⅴ — The Constellation

*Was it ever really gone?*

What disappeared becomes something else — a constellation made from the memory you left behind.

### Ⅵ — The Afterlight

*What will you leave for someone else?*

The final question isn't about what you want to keep.

It's about what you want someone else to find.

## Why I Made This

We spend a lot of time trying to preserve things.

Photos.
Messages.
Voices.
Places.
People.
Little moments that probably seemed ordinary when they happened.

But we rarely stop to ask **why** we want to keep them.

This project is an attempt to turn that question into something you can actually experience.

Not a productivity tool.
Not a social platform.
Not another thing asking you to scroll.

Just a few minutes in the dark.

---

## The Experience

The visual language starts almost entirely in darkness, with the dying sun carrying warmer tones.

As the story progresses, the palette slowly moves through:

`Black → Red → Violet → Indigo → Blue → Pale Gold`

The world doesn't become brighter again.

It becomes **different**.

The constellation is also generated from the memory the user chooses, so the final sky feels connected to the beginning of their journey.

## Running It Locally

Clone the repository:

```bash
git clone https://github.com/thisisaunam/If-the-sun-burns-out-tonight.git
```

Open the project with a local server.

For example, using VS Code + Live Server, open:

```text
index.html
```

Keep the project structure intact, especially the `assets` folder containing the audio.

```text
If-the-sun-burns-out-tonight/
├── index.html
├── style.css
├── script2.js
```
